# Connection types

**Wired connections**

- Cable
    - Physical connection
    - Coaxial cables same as cable TV
    - Cable modem operates over cable TV lines → 10 Mbps to 1 Gbps
- DSL
    - Sends signals through phone lines
    - Simultaneous phone and internet use
    - 2 wire copper line and DSL modem → 5 to 120 Mbps
    - Rare outside rural areas
    - Slower speeds due to resistance
    - Speed depends on distance
- ISDN
    - Integrated services digital network
    - Circuit-switched telephone network
    - Transmits data, phone calls, videos
    - Phased out, too expensive and less flexible

**Wireless connections**

- Wi-Fi
    - Uses radio waves to provide high-speed internet access
    - Sends request to devices which send signal back
    - Inexpensive
    - Wide coverage
    - Users can move freely
- Cellular
    - Any way mobile devices make a connection
    - Cell towers send radio signals

**VPN connections**

- Encrypted tunnel
- Changes IP address

**LAN**

- Exclusive access to the same system connection
- Can span multiple buildings

Which one to choose? Consider:

- Speed
- Cost
- Reliability
- Data usage needs
- Availability
- Security features
